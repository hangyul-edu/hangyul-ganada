# The ambiguity ledger

GENERATED by `npm run ambiguity:ledger`. Do not edit by hand — edit
`content/vocabulary/ambiguity-review.json` and rebuild.

A question is acceptable only when exactly one of the choices in front of the
learner is correct. Checking that the stored answer id is unique does not
establish that, and this repository has now been caught twice believing it did.
This file records both halves of the check: what the gates can decide, and what
a person had to read.

## 5. What this ledger does not cover

* 1,761 meaning items and 1,761 produce items carry one gloss per taught sense; a distractor sharing the answer's meaning in any of the 32 locales is rejected by collideInAnyLocale at build time. Read as a spread rather than exhaustively — see the limit recorded in docs/AMBIGUITY_LEDGER.md.
* Whether a translated choice reads naturally to a native speaker of that language.
  The 24 locale packs are machine-assisted and unreviewed; `docs/report.md` carries
  that blocker and this file does not close it.
* Whether audio introduces a second reading. The listening questions were read as
  text and their clips were checked for existence and duration, not listened to.
