# The ambiguity ledger

GENERATED by `npm run ambiguity:ledger`. Do not edit by hand — edit
`content/vocabulary/ambiguity-review.json` and rebuild.

A question is acceptable only when exactly one of the choices in front of the
learner is correct. Checking that the stored answer id is unique does not
establish that, and this repository has now been caught twice believing it did.
This file records both halves of the check: what the gates can decide, and what
a person had to read.

## 2. What the gates decide

| Gate | Reads | Refuses |
|:---|:---|:---|
| `leveltest:ambiguity` | the shipped bank | 27 rules, including a stem that says only *when*, a predicate that rules out no noun, two people in one agent slot, and every reviewed pair |
| `questions:ledger` | all three surfaces | duplicate options after NFKC, an answer that is not among the options or is there twice, an answer index that is not an index, one stem keyed two ways |
| `answerability` | all three surfaces | a question answerable without reading it |
| `numbers:qa`, `numbers:domain` | the Numbers course | a distractor filling the same slot as the key, a counter and number that disagree |
| `copy:fresh` | the 24 locale packs | an example translation whose Korean sentence has since changed |

Their limit is stated rather than implied: none of them reads Korean. Every rule
above is a proxy for a judgement, which is why section 3 exists.
