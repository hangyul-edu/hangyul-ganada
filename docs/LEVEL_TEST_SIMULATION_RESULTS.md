## Resume and reassessment

An interrupted sitting replayed from five points — after 1, 3, 7, 12 and 18 answers — presents the identical questions in the identical order and reports the identical level: **confirmed**. Selection is a pure function of the stored seed and the question index, so there is nothing else it could do; the assertion exists because that was not true of an earlier engine.

A retake is a fresh sitting. A stored level steers the opening ladder and reaches
nothing else — not the posterior and not the earned ceiling — so a learner whose stored
level is wrong is not held to it. `leveltest:qa` measures a retake carrying the *worst
possible* stored level and reports the same accuracy as a first sitting.

## What these simulations are not

The simulated learner answers the way the model says a learner of that ability would.
That makes them a check on the machinery and not on the difficulty scale underneath it:
a simulation reports excellent behaviour for a badly calibrated bank for exactly as long
as the bank is wrong in the same way the simulation is. No learner response data exists
in this repository to calibrate against, and none can be collected — the application
opens no network connection. See `docs/LEVEL_TEST_DIFFICULTY_AUDIT.md`.
