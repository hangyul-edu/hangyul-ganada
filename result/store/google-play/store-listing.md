# Play Store listing — what goes in which field

The copy itself is in `../listing/<locale>.md`, one file per language, and is
checked against Play's limits by `npm run store:check`. This maps those files
onto the Console form and records the choices that are not copy.

## Fields

| Console field | Source | Limit |
| --- | --- | --- |
| App name | `## Title / App name` | 30 |
| Short description | `## Short description (Play)` | 80 |
| Full description | `## Full description` | 4000 |
| Default language | `en-GB` | — |
| Other languages | ko, ja, zh-CN, es, fr, de, pt-BR | — |

The `## Subtitle (App Store)` and `## Keywords (App Store)` sections in those
files are for App Store Connect and have no Play equivalent. Play has no
keywords field: it indexes the description.

## Graphics

| Asset | Requirement | Where |
| --- | --- | --- |
| App icon | 512 × 512 PNG, 32-bit, no alpha on the store tile | generated by `npm run mobile:icons` from `apps/web/public/brand/logo-symbol.png` |
| Feature graphic | 1024 × 500 | **not produced** — see the blockers file |
| Phone screenshots | 2–8, min 320 px, max 3840 px, 16:9 to 9:16 | `docs/store-assets/android/*.png`, 1080 × 2400, captured from the app running on an Android 16 emulator |

The screenshots are real frames from the running app — `adb exec-out screencap`
against the installed binary, including the status and gesture bars — rather than
a browser at a phone-shaped viewport. That distinction matters for a submission:
a browser screenshot has no system bars, the wrong corner radius and the wrong
font rendering, and reviewers notice.

## Contact details

| Field | Value |
| --- | --- |
| Email | **not set** — see `../../result/BUILD_OR_SIGNING_BLOCKERS.md` |
| Website | **not set** — the privacy policy and support pages exist as documents and are not yet hosted |
| Phone | not provided (optional) |

Both are required by Play before a listing can be published, and neither can be
invented here: an address nobody owns and a URL nobody has registered are worse
than an empty field, because an empty field cannot be submitted by mistake.
