# Content rating — IARC questionnaire

The same questionnaire feeds Play, and the App Store asks a shorter version of
it. Every answer is **No** unless stated.

| Section | Answer |
| --- | --- |
| Violence — realistic, fantasy, or implied | No |
| Sexuality or nudity | No |
| Profanity or crude humour | No. The vocabulary pack removes coarse language explicitly, with the reason recorded per word: see the `k: 0` entries in `content/vocabulary/entries/`. |
| Controlled substances — drugs, alcohol, tobacco | No. 술 ("alcohol") and 담배 ("cigarette") appear as ordinary nouns in a beginner vocabulary, with neutral example sentences and no depiction of use. |
| Gambling, real or simulated | No |
| Horror or fear themes | No |
| Discrimination | No |
| User-generated content or user interaction | No. There is no chat, no comments, no profiles, no sharing between users. |
| Shares user location | No |
| Allows purchases | No in-app purchases. The app is bought once, through the store. |
| Contains advertising | No |
| Unrestricted web access | No. The app opens no browser; the Content sources screen links to licence pages, which open in the system browser and are the only outbound links. |

**Expected rating:** *Everyone* / PEGI 3 / 全年齢 — an educational app with no
objectionable content, no purchases, no ads and no communication features.

**Data collection questions** are answered in `data-safety.md`.
