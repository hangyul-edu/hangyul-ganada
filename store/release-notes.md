# Release notes — 1.0.0

Both stores show this to customers. It is the first release, so it says what the
app is rather than what changed.

Two things in the previous draft of this file were not true of the product and
were corrected in the final pass: it offered **2,504** words where the corpus
had 2,581, and it promised **a picture with every word**. The illustrations were
removed a cycle earlier — data, assets, pipeline and all — because a picture
gives a word's meaning away before any Korean has been read. A store listing is
the one place a wrong claim becomes a refund request, so both were fixed in all
eight languages, and `npm run store:check` now runs against this file too.

## English

First release.

Learn to read and write Hangul from the first letter: 40 letters, 33 syllable
blocks and 3,220 everyday words, each with an example sentence and recordings in
two Korean voices. Every letter shows the order its strokes are made in, and
your handwriting is checked as you draw it. Everything works offline, there is no
account, and nothing leaves your device.
